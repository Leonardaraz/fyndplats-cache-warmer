# Kort beskrivning (svenska)

Endast **Google Play** har ett kort beskrivningsfält. Apple använder Subtitle
(se [`app-name.md`](app-name.md)) i stället.

## Google Play – Short description

| Fält | Tecken | Max |
|---|---|---|
| Short description | 70 | 80 |

```
Noga utvalda fynd till smarta priser. Klarna och fri frakt över 499 kr.
```

## Anteckningar

- Visas högst upp på Play-listningen, ovanför "Läs mer"-vikningen — det första
  (ofta enda) en användare läser. De viktigaste säljpunkterna ska in här:
  **utvalda fynd**, **smarta priser**, **Klarna**, **fri frakt**.
- Google indexerar fältet för sök, så `fynd`, `priser`, `Klarna` och `frakt`
  bär dubbel last (säljande + sökord).
- Ingen versalisering av hela ord, inga emojis, inga upprepade skiljetecken —
  Play kan flagga sådant som "spammigt".
