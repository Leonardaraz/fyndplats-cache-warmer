# Versionsnyheter (svenska)

"What's New" / "Nyheter i denna version". Apple max **4000 tecken**, Google Play
max **500 tecken**. Håll det kort och konkret – håll dig under 500 så samma text
fungerar i båda butikerna.

Lägg nya versioner överst.

---

## v1.0.0

```
Första version! Hela Fyndplats i fickan – bläddra, köp, spåra direkt från appen.
```

---

## Mall för kommande versioner

```
v1.x.x:
• [Ny funktion]
• [Förbättring]
• Buggfixar och prestandaförbättringar
```

## Anteckningar

- Skriv vad användaren faktiskt märker, inte interna tekniska detaljer.
- "Buggfixar och prestandaförbättringar" som enda rad funkar för småreleaser men
  undvik den för större uppdateringar – konkreta nyheter ger bättre konvertering.
- Engelsk motsvarighet finns i [`release-notes-en.md`](release-notes-en.md) –
  uppdatera båda samtidigt.
