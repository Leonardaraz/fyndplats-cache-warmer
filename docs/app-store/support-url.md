# Support-URL

Obligatoriskt i båda butikerna (Apple: *Support URL*; Google Play: *Support
website* under kontaktuppgifter).

```
https://www.fyndplats.se/kontaktaoss
```

## Anteckningar

- Sidan måste vara live, nåbar utan inloggning och innehålla ett sätt att kontakta
  kundtjänst (formulär, e-post eller telefon) — granskare klickar på den.
- Verifiera att URL:en svarar 200 innan submission. Slug:en är `kontaktaoss`
  (utan bindestreck) — bekräfta mot live-sajten så den inte ändrats.
