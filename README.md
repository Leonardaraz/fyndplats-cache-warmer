# Bildklossar för poleringen

Fyra produktbilder som tvättats rena från inbränd engelsk text inför
SEO-poleringen av NCLAGEN-batchen. Grenen är föräldralös och innehåller
bara bilderna — den finns för att ge dem publika raw-URL:er så att de kan
laddas upp till Wix Media Manager i ett anrop.

| Fil | Produkt |
|---|---|
| `bilder/n32-linne-blagra-narbild.jpg` | Träningslinne med inbyggd bh |
| `bilder/n33-sportbh-fargstang.jpg` | Sport-bh med lätt stöd |
| `bilder/n37-halterlinne-modell.jpg` | Halterneck-linne med rynkad framsida |
| `bilder/n38-leggings-modell.jpg` | Sömlösa leggings med låg ribbad midja |

När bilderna ligger i Wix kan grenen tas bort.
